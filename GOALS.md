# AI Me Guides mission

Help beginners build a growing personal knowledge collection, starting with useful information from existing AI chats. Offer a complete guide and a shorter source-guided route with practical prompts.

Maintain standalone documentation without personal records, private project references, machine-specific paths or inherited repository history. No application code is planned now. Preserve source attribution and distinguish guidance from software that has actually been tested.

Prepare the exact candidate files for the user's review. Repository operations and publication require explicit approval; making a repository public is a separate decision.
